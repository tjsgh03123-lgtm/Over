# 앱 콘텐츠 / 데이터 보안 답안 (이 앱 기준)

## 데이터 보안
- 앱에서 사용자 데이터를 수집하거나 공유하나요? → **아니요**
  - 기록은 기기 안에만 저장하고, 카메라 영상은 기기에서만 처리하며 외부로 보내지 않습니다.
  - 사용자가 직접 '내보내기'를 눌러 파일을 공유하는 것은 수집에 해당하지 않습니다.
- 전송 중 암호화 / 삭제 요청 방법 질문은 '수집 없음'이면 나오지 않습니다.

## 개인정보처리방침
- URL 입력 (listing-ko.md 참고)

## 광고
- 앱에 광고가 포함되어 있나요? → **아니요**

## 앱 액세스
- 모든 기능을 로그인 없이 사용 가능 → "특별한 액세스 권한 불필요"

## 콘텐츠 등급 (IARC 설문)
- 카테고리: 유틸리티/생산성/기타(참조용 앱)
- 폭력, 성적 콘텐츠, 욕설, 약물, 도박, 사용자 간 소통, 위치 공유, 디지털 구매 → 모두 **아니요**

## 타겟층
- **만 18세 이상**만 선택 (어린이 정책 대상이 되지 않도록)

## 건강 앱 선언
- 카테고리가 건강 및 운동이므로 '건강 앱 선언' 양식이 나옵니다. 아래로 답하세요.
  - 건강 데이터 사용: 사용자가 직접 입력한 운동·체중 기록만, 기기 안에만 저장
  - 의료 기기 아님, 진단·치료 기능 없음

## 권한 (앱 설명 시 근거)
- CAMERA: 운동 횟수 세기 기능에서만 사용
- 그 외 위험 권한 없음 (위치·연락처·마이크·저장소 전체 접근 없음)

## 기타
- 정부 앱/금융/뉴스 앱 아님, COVID-19 앱 아님
- 대상 SDK(targetSdk)는 Expo SDK 54 기본값을 사용 (워크플로 로그의 "targetSdk" 줄로 확인)
